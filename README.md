# Climate City — Mivora theme

Climate City website using the user-supplied Mivora Next v1.0 template. Original section order, colours, responsive proportions, image placeholders, illustrations and animations are preserved. Copy and navigation use Climate City information.

## Development

Run `npm ci`, then `npm run dev`. `npm run build` produces a static website in `out/`. Vercel serves this export with clean URLs.

## Pages

- `/`: Mivora homepage adapted for Climate City
- `/about`: project background and philosophy
- `/sustainable-design`: design approach and delivery stages
- `/leadership`: CEO and COO profiles
- `/mikoshel`: company background
- `/contact`: enquiries via the supplied WhatsApp number
- `/explore.html`: existing interactive masterplan and destination journeys

Template photographs and sample brand graphics are retained as requested; they do not depict completed Climate City facilities or confirmed partnerships. The masterplan is conceptual and the project is proposed. No sustainability certification, investment return or operating-facility claims are made.

The previous static build remains in Git history. Source assets for the interactive experience are in `public/assets/`.
